# Illinois Education Enrollment Analysis

A portfolio project demonstrating SQL, Python/ETL, and Tableau skills 
in an educational data context.

## Dashboard
[View Live Dashboard on Tableau Public](https://public.tableau.com/app/profile/saahil.sorakayala/viz/IllinoisEducationEnrollmentAnalysis2024-25/Dashboard1)

## Project Overview
Analyzes 2024-25 Illinois student enrollment data from the NCES 
Common Core of Data, focusing on Oak Park & River Forest District 200.

## Skills Demonstrated
- Python (pandas) — ETL pipeline processing 15 million rows
- SQLite — database creation and SQL analysis queries
- Tableau Public — interactive dashboard and data visualization

## Data Source
NCES Common Core of Data 2024-25
https://nces.ed.gov/ccd/files.asp

## Project Structure
- `scripts/` — Python ETL notebook
- `sql/` — SQL analysis queries
- `docs/` — documentation and data dictionary
- `data/` — cleaned CSVs (not included, see data source above)

## Key Findings
- OPRF High School ranks 17th largest in Illinois with ~3,200 students
- Illinois is a majority-minority state with White students at 44.6%
- Hispanic/Latino students are the second largest group statewide at 28.6%
- OPRF student body is 60.6% White, 19% Hispanic/Latino
